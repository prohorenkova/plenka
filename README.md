# ПленкаКИНО — интерактивный сервис бронирования мест в кинотеатрах Санкт-Петербурга

## 1. О проекте

**ПленкаКИНО** — учебный веб-проект, разработанный в рамках практического задания № 4 «Интерактивная карта и живой интерфейс бронирования».

Сайт представляет собой интерактивный каталог кинотеатров Санкт-Петербурга. Пользователь может выбрать кинотеатр на схематичной карте или в списке, подобрать фильм и сеанс, выбрать места в кинозале, оформить учебное бронирование и просмотреть свои билеты.

## 2. Цель проекта

Разработать интерактивный сайт на HTML, CSS и JavaScript, демонстрирующий работу с динамическими элементами интерфейса, пользовательскими действиями, формами, расчётом стоимости и сохранением данных в браузере.

## 3. Основной функционал

### Каталог кинотеатров
- Отображение 8 кинотеатров Санкт-Петербурга.
- Список кинотеатров с названиями, адресами, районами, станциями метро и стоимостью билетов.
- Интерактивная схематичная карта расположения кинотеатров.
- Синхронизация карты и списка: выбор кинотеатра в одном элементе выделяет его в другом.

### Фильтрация
- Фильтр по административному району.
- Фильтр по максимальной стоимости билета.
- Одновременное обновление списка и карты при изменении параметров.
- Возможность сбросить фильтры.

### Выбор фильма и бронирование
- Выбор кинотеатра.
- Выбор фильма, даты и времени сеанса.
- Схема кинозала из 24 мест (4 ряда по 6 мест).
- Выбор нескольких свободных мест.
- Визуальное обозначение свободных, выбранных и занятых мест.
- Блокировка занятых мест.
- Автоматический расчёт итоговой стоимости билетов.

### Оформление бронирования
- Ввод имени и электронной почты пользователя.
- Проверка наличия выбранных мест.
- Проверка имени и корректности электронной почты.
- Повторная проверка доступности мест перед созданием брони.
- Создание бронирования после подтверждения.

### Раздел «Мои билеты»
- Отображение оформленных бронирований.
- Информация о кинотеатре, фильме, дате, времени и выбранных местах.
- Отображение итоговой стоимости.
- Возможность отменить бронирование.
- Автоматическое освобождение отменённых мест.
- Сохранение данных после обновления страницы с помощью `localStorage`.

### Дополнительные возможности
- Кнопка сброса демонстрационных бронирований.
- Уведомления об успешных действиях и ошибках.
- Адаптивные стили для мобильных экранов.
- Поддержка клавиатурной навигации и видимого фокуса интерактивных элементов.

## 4. Визуальная концепция

Визуальный стиль проекта — **«Цифровой брутализм и андеграундная киноафиша»**.

Дизайн объединяет эстетику независимого кино, печатной графики и аналоговых носителей. В оформлении используются:
- холодная голубовато-серая цветовая палитра;
- растровые текстуры и эффект печатной поверхности;
- контрастная типографика;
- геометрические элементы и модульная сетка;
- стилизованная карта Санкт-Петербурга;
- графические элементы, отсылающие к киноплёнке и аналоговой фотографии.

## 5. Используемые технологии

- **HTML5** — структура веб-страницы.
- **CSS3** — оформление, адаптивная вёрстка и визуальные эффекты.
- **JavaScript (Vanilla JS)** — интерактивность, фильтрация, выбор мест и логика бронирования.
- **JavaScript ES Modules** — разделение логики и данных по отдельным файлам.
- **localStorage** — локальное сохранение пользовательских бронирований.
- **Google Fonts** — подключение веб-шрифтов.

Для разработки и проверки проекта использовались Visual Studio Code и расширение Live Server.

## 6. Структура проекта

```text
kino_peterburg/
├── index.html
├── styles.css
├── README.md
├── images/
│   ├── maps.png
│   ├── plenka.svg
│   └── plenka2.svg
└── js/
    ├── app.js
    └── data.js
```

Назначение основных файлов:
- `index.html` — структура сайта.
- `styles.css` — стилизация и адаптивная вёрстка.
- `js/app.js` — логика интерфейса, фильтрация, выбор мест, оформление и отмена бронирований.
- `js/data.js` — данные кинотеатров, цены, фильмы, сеансы, координаты меток и первоначально занятые места.
- `images/maps.png` — фоновое изображение карты.
- `images/plenka.svg` — графический логотип проекта.

*Примечание: названия файлов и папок в примере структуры должны совпадать с фактической структурой проекта.*

## 7. Запуск проекта

1. Открыть папку проекта в Visual Studio Code.
2. Проверить, что файлы `index.html`, `styles.css` и папка `js` находятся на указанных местах.
3. Запустить `index.html` с помощью расширения **Live Server**.
4. Открыть локальный адрес сайта в браузере.

Проект не требует установки npm-пакетов, сборки или подключения сервера. Для загрузки веб-шрифтов Google Fonts требуется подключение к интернету.

## 8. Ограничения проекта

Проект является учебной демонстрацией системы бронирования.

- Реальная покупка билетов и оплата не предусмотрены.
- Регистрация и авторизация пользователей отсутствуют.
- Данные сохраняются только в `localStorage` текущего браузера.
- Бронирования не синхронизируются между устройствами.
- Стоимость билетов, фильмы, сеансы и первоначальная занятость мест являются демонстрационными данными.
- Карта представляет собой условную схему и не предназначена для точной навигации.

**Учебное демо: реальные билеты и оплата не оформляются.**

> Создай интерактивный сайт кинотеатров Санкт-Петербурга на HTML, CSS и ванильном JavaScript. Добавь каталог из восьми кинотеатров, интерактивную карту, список площадок и систему выбора кинотеатра.

**2. Реализация бронирования**

> Добавь выбор фильма, даты и времени сеанса, схему кинозала из 24 мест, возможность выбирать несколько свободных мест, автоматический расчёт стоимости и оформление бронирования.

**3. Доработка интерфейса**

> Переработай визуальный стиль сайта в эстетике цифрового брутализма и андеграундной киноафиши. Используй холодную цветовую палитру, растровые текстуры, эффект печатной поверхности и техническую типографику. Сохрани существующую функциональность.
